# Consultora societaria — sitio web

Sitio institucional de la consultora (nombre a definir): constitución de sociedades (SA, SRL, SAS, unipersonales), asociaciones civiles y fundaciones; contabilidad y libros.

## Estructura
- `index.html` — página completa (HTML, CSS y JS en un solo archivo).
- `vercel.json` — configuración de publicación en Vercel.

## Próximos pasos
1. GitHub: guardar el código (este repositorio).
2. Vercel: publicar el sitio conectado a este repositorio.
3. Supabase: acceso de clientes por invitación (correo y contraseña), datos y documentos.
4. Railway: funciones de servidor que lo requieran.
5. Resend: correos (invitaciones, avisos de trámites, formularios).

> Los honorarios y algunas tasas del cotizador son valores de ejemplo.
